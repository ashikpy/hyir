# Hyr · Job Application Command Center

A fast, high-contrast, keyboard-first job hunt and application tracking system built for modern designers and engineers.

## Features

- **Pipeline Kanban**: Visual stage progression (Saved, Applied, Interviewing, Offer, Rejected).
- **Command Palette (<kbd>⌘K</kbd>)**: Instant Spotlight-style search across companies, roles, and contacts.
- **Auto-complete**: Free real-time OpenStreetMap location autocomplete & curated design/tech roles.
- **Import & Export**: RFC 4180-compliant CSV and JSON import/export with live previews and conflict resolution.
- **Activity Timeline**: Full milestone logging for follow-ups, recruiter calls, and status transitions.
- **Dark Mode Aesthetic**: Ultra-clean zinc dark mode with custom slim scrollbars.

## Tech Stack

- **Framework**: Next.js 16 (App Router & Turbopack)
- **Database & ORM**: Neon Serverless PostgreSQL & Prisma ORM
- **Styling**: Tailwind CSS & Lucide Icons
- **Runtime**: Bun / Node.js

## Getting Started

```bash
bun install
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
